# WhatsApp Private — actualizaciones

[Descargar la última versión para Windows](https://github.com/indignatesilentdark/whatsapp-private-updates/releases/latest)

Canal de distribución de WhatsApp Private. Aquí se publican solamente binarios, ZIP, comprobaciones SHA256 y la automatización para publicarlos. El código de la personalización se conserva por separado.

La versión 1.7.0 activa las actualizaciones automáticas. Las versiones nuevas se descargan en segundo plano, se verifican y se instalan al volver a abrir la app. La sesión y los ajustes permanecen locales.

Aplicación independiente basada en [vianziro/Whatsapp-Dekstop](https://github.com/vianziro/Whatsapp-Dekstop), bajo licencia MIT incluida en el ZIP. No afiliada a WhatsApp o Meta.
