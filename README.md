# WhatsApp Private

[**Descargar instalador de Windows (recomendado)**](https://github.com/indignatesilentdark/whatsapp-private-updates/releases/latest/download/WhatsApp-Private-Windows-x64-Setup.exe)

[Descargar ZIP portable](https://github.com/indignatesilentdark/whatsapp-private-updates/releases/latest/download/WhatsApp-Private-Windows-x64.zip) · [Ver todas las versiones y SHA256SUMS](https://github.com/indignatesilentdark/whatsapp-private-updates/releases)

El instalador no requiere permisos de administrador. Instala para tu usuario en `%LOCALAPPDATA%\Programs\WhatsApp Private`, crea accesos en Inicio y escritorio y permite desinstalar desde Aplicaciones instaladas de Windows. Antes de instalar o desinstalar, cierra la app desde su icono junto al reloj, con **Salir**.

La sesión y los ajustes se conservan en `%APPDATA%\WhatsAppDesk`, incluso al desinstalar. La versión instalada y la portable comparten ese perfil: utiliza una sola copia a la vez.

Las versiones nuevas se descargan automáticamente, se verifican con SHA256 y se aplican al volver a abrir la app. También puedes elegir **Reiniciar y actualizar**. Las versiones anteriores a 1.7.0 necesitan descargar una versión actual una vez.

Usa siempre los archivos de **Releases** para obtener la versión más reciente. Este repositorio solo distribuye binarios, ZIP, comprobaciones y la automatización de publicación; el código de la personalización se conserva por separado.

Aplicación independiente basada en [vianziro/Whatsapp-Dekstop](https://github.com/vianziro/Whatsapp-Dekstop), bajo licencia MIT incluida en las descargas. No afiliada a WhatsApp o Meta.
